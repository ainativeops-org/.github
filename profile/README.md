# AiNativeOps

An open reference model of operations in which AI agents create, change and verify the target system across its life cycle, from data and models to code and release. A control loop takes the release decision: deterministic checks, an AI controller and an accountable human act at control gates G0–G9.

**Community Interest Project · alpha 0.1**

- **[Interactive map](https://ainativeops.org)** — architecture, infrastructure and platform stack views, 7 scenarios, Russian and English.
- **[Model repository](https://github.com/ainativeops-org/ainativeops)** — the model as YAML, the build tools and the contribution guide.
- **[Discussions](https://github.com/ainativeops-org/ainativeops/discussions)** — RFCs and open questions.

The model names no vendors: every class can be implemented by any product. Proposals and comments are welcome; the map has a "Suggest an edit" button on every element.
